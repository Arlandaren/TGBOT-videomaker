# ReelBot: правила для агентов

В этой папке одновременно работают несколько сессий Claude, в одной рабочей
копии и в одной ветке `main`. Чтобы не затирать чужую работу, есть доска.

## Перед началом работы

1. Посмотри доску: `.venv/Scripts/python.exe tools/board.py`. Она показывает,
   кто что делает, какие файлы изменены и чьи они, и какие коммиты ещё не ушли в
   origin (их нет на проде и нет у других машин).
2. Запиши свою заявку — задачу и файлы, которые собираешься править:
   `.venv/Scripts/python.exe tools/board.py claim --agent <имя сессии> --task "что делаю" файл1 файл2`
   Имя сессии показывает `ListAgents` («This session is ...»). Новые файлы по
   ходу работы добавляй тем же вызовом с `--add`.
3. Если файл уже в чужой заявке — не правь его молча. Напиши той сессии
   (`SendMessage`) или скажи пользователю.

## По ходу и в конце

- Чужие незакоммиченные правки не трогай: никаких `git stash`, `git checkout --`,
  `git reset`, `git add -A` и `git commit -a`. В коммит клади только свои файлы,
  поимённо.
- Закончил и закоммитил (или бросил задачу) — сними заявку:
  `.venv/Scripts/python.exe tools/board.py done --agent <имя сессии>`.
- Пуш в `main` выкатывает на прод. Без просьбы пользователя не пушить.

Страница доски для человека: `.venv/Scripts/python.exe tools/board.py html --watch`
пересобирает `.git/agents-board/board.html` каждые 5 секунд.
