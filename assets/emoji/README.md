# Шрифт эмодзи

`NotoColorEmoji.ttf` — Noto Color Emoji (Google), лицензия SIL Open Font
License 1.1: https://github.com/googlefonts/noto-emoji

Им рисуются значки в ролике: плашка пункта перечисления и значок карточки. На
сервере рендера эмодзи-шрифта в системе нет, поэтому файл лежит в репозитории и
едет в бандл рендера вместе с роликом — только когда в плане есть значки
(`src/pipeline/render.py`, `prepare_assets`).

Лежит отдельно от `assets/fonts`: там шрифты текста, у каждого выгружены метрики
и каждый сверяется с Chromium. Этому метрики не нужны — значок стоит в окошке
фиксированной ширины.
