# Фоновая музыка

Здесь лежит библиотека треков, из которой бот подбирает музыку под смысл ролика
(галочка «Фоновая музыка» в приложении, `src/pipeline/music.py`), и сюда же
можно положить свой трек для темы.

## Библиотека: `catalog.json` и `*.m4a`

Каждая строка каталога — один трек: ключ, файл, настроение, описание, лицензия,
автор и страница, откуда он взят. Модель видит ключ, настроение и описание и
выбирает ключ; файл под голос кладёт сведение (`src/pipeline/audio_post.py`).

**В библиотеке только треки, которые можно вставлять в чужой коммерческий ролик
без указания автора**: CC0, общественное достояние или собственная запись
(`license`: `cc0`, `pdm`, `own`). Строка с другой лицензией не загружается —
это проверка в коде. CC BY не годится: бот не может заставить человека
подписать автора под рилсом. У бесплатных библиотек лицензии на соседних файлах
отличаются, поэтому страница трека записана в каталоге (`source`) — её можно
открыть и перепроверить.

Собирает библиотеку `tools/music_fetch.py` (каталог Openverse, источник
Freesound, только CC0; денег и ключей не нужно):

```
python tools/music_fetch.py                      # добрать до 3 треков на настроение
python tools/music_fetch.py --listen музыка.html # страница с плеерами — послушать
python tools/music_fetch.py --drop calm-02       # убрать неудачный трек
```

Скрипт отсеивает по тегам, длине и разбросу громкости, приводит громкость к
−16 LUFS и режет до полутора минут. **Слушать он не умеет** — хорош ли трек,
решает человек: пройтись по странице `--listen` и убрать лишнее.

Свой трек в библиотеку: положить файл сюда, привести к −16 LUFS и дописать
строку в `catalog.json` с `"license": "own"`.

Пока каталога нет или в нём ни одного годного трека, галочка в приложении не
показывается, а ролики собираются без музыки.

## Свой трек для темы

1. Положить файл рядом с этим README: `assets/music/calm-loop.mp3`
   (подходят `.mp3`, `.m4a`, `.wav`, `.ogg`, `.opus`, `.flac`, `.aac`).
2. Прописать имя в пресете, секция `audio`:

```json
"audio": {
  "music": "calm-loop.mp3",
  "music_gain_db": -20,
  "duck_db": -12,
  "music_fade_s": 0.5
}
```

Трек зациклится под длину ролика, получит фейды на входе и выходе и будет
приседать под голос на `duck_db`. Путь к папке меняется переменной `MUSIC_DIR`.

Что главнее: трек, который человек вставил по ссылке, → трек, подобранный
галочкой «Фоновая музыка», → трек темы.

## Что искать

Подложка под говорящую голову — это не «трек», а фон: без вокала, без резких
барабанов, без явного развития. Трек с тихим вступлением и громким припевом
будет то пропадать, то лезть вперёд, и никакой дакинг это не исправит.
